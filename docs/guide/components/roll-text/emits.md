## Events

---
| EmitName | Arguments | Statement |
|:--------:|:---------:|:----------|
| start | - | Emitted when the animation starts. |
| iteration | - | Emitted each time a repeated or bounced cycle completes. |
| end | - | Emitted when a finite animation finishes. |

## Slots

---
1. Default

The default slot contains the text to be scrolled.

```javascript
<fv-roll-text>
    Content
</fv-roll-text>
```
